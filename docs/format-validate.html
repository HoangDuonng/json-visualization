What is Format & Validate?

Format & Validate provides two essential features for working with structured data:

Formatting (Beautify)

Automatically formats your data with proper indentation, spacing, and structure, making it easier to read and maintain.

Validation

Checks your data for syntax errors, structural issues, and format violations in real-time, providing immediate feedback.

Supported Formats

Format & Validate works with the following data formats:

JSON

• Validates JSON syntax

• Checks for missing commas, brackets, and quotes

• Formats with customizable indentation

• Detects trailing commas and other common errors

YAML

• Validates YAML syntax

• Checks indentation consistency

• Detects invalid characters and structure

• Preserves comments during formatting

CSV

• Validates CSV structure

• Checks for consistent column counts

• Detects malformed rows

• Handles quoted fields correctly

How to Use

Automatic Formatting

1. Open the Editor

2. Paste or type your data

3. The editor automatically formats your data with proper indentation and spacing

4. Use Ctrl+S (Cmd+S on Mac) to manually trigger formatting

Real-time Validation

1. As you type, the editor validates your data in real-time

2. Syntax errors are highlighted with red underlines

3. Hover over errors to see detailed error messages

4. The bottom toolbar shows validation status and error count

Error Navigation

1. Click on error indicators in the gutter (left side of editor)

2. Use keyboard shortcuts to jump between errors

3. Check the bottom toolbar for a summary of all errors

Common Validation Errors

JSON Errors

Missing Comma

Invalid:

{
  "name": "John"
  "age": 30
}

Valid

{
  "name": "John",
  "age": 30
}

Trailing Comma

Invalid:

{
  "name": "John",
  "age": 30,
}

Valid

{
  "name": "John",
  "age": 30
}

Unquoted Keys

Invalid:

{
  name: "John",
  age: 30
}

Valid

{
  "name": "John",
  "age": 30
}

Single Quotes

Invalid:

{
  'name': 'John',
  'age': 30
}

Valid

{
  "name": "John",
  "age": 30
}

YAML Errors

Inconsistent Indentation

Invalid:

person:
  name: John
   age: 30

Valid

person:
  name: John
  age: 30

Missing Space After Colon

Invalid:

name:John
age:30

Valid

name: John
age: 30

CSV Errors

Inconsistent Column Count

Invalid:

name,age,city
John,30,New York
Jane,25

Valid

name,age,city
John,30,New York
Jane,25,Boston

Formatting Options

The editor provides several formatting options:

Indentation

• Default: 2 spaces

• Consistent indentation throughout the document

• Automatically adjusts nested structures

Line Breaks

• Proper line breaks between elements

• Consistent spacing for readability

Sorting (Optional)

• Sort object keys alphabetically

• Useful for comparing JSON files

Tips & Best Practices

• Fix Errors as You Go

Address validation errors immediately to avoid cascading issues in your data structure.

• Use Consistent Formatting

Let the editor handle formatting automatically to maintain consistency across your files.

• Check Error Messages

Hover over error indicators to see detailed messages that explain what's wrong and how to fix it.

• Validate Before Sharing

Always ensure your data is valid before sharing it with others or using it in production.

• Use JSON Schema for Advanced Validation

For more complex validation rules, use JSON Schema to define custom validation logic.
