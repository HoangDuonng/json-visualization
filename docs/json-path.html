What is JSONPath?

JSONPath is a query language for JSON, similar to XPath for XML. It allows you to select and extract data from JSON documents using path expressions.

The root element is always referred to as $ regardless of whether it's an object or array. From there, you can navigate through the structure using dot notation or bracket notation.

How to Use

1. Open the Editor

Load your JSON data in the JSON Visualization Editor.

2. Open JSON Path Tool

Click on "Tools" in the toolbar and select "JSON Path".

3. Enter Your Path Expression

Type your JSONPath expression in the input field and click "Run".

4. View Results

The extracted data will be displayed in the editor.

Basic Syntax

OperatorDescription
$Root element
@Current element (used in filters)
.Child operator (dot notation)
..Recursive descent (search all levels)
*Wildcard (all elements)
[]Subscript operator (array index or object property)
[,]Union operator (multiple indices or properties)
[start:end]Array slice operator
[?()]Filter expression

Practical Examples

Sample JSON Data:

{
  "store": {
    "book": [
      {
        "category": "reference",
        "author": "Nigel Rees",
        "title": "Sayings of the Century",
        "price": 8.95
      },
      {
        "category": "fiction",
        "author": "Evelyn Waugh",
        "title": "Sword of Honour",
        "price": 12.99
      },
      {
        "category": "fiction",
        "author": "Herman Melville",
        "title": "Moby Dick",
        "isbn": "0-553-21311-3",
        "price": 8.99
      }
    ],
    "bicycle": {
      "color": "red",
      "price": 19.95
    }
  }
}

Example 1: Get all books

Path:

$.store.book[*]

Returns all book objects in the array

Example 2: Get all book authors

Path:

$.store.book[*].author

Result:

["Nigel Rees", "Evelyn Waugh", "Herman Melville"]

Example 3: Get all prices in the store

Path:

$.store..price

Result:

[8.95, 12.99, 8.99, 19.95]

The .. operator searches recursively

Example 4: Get the first book

Path:

$.store.book[0]

Result:

{
  "category": "reference",
  "author": "Nigel Rees",
  "title": "Sayings of the Century",
  "price": 8.95
}

Example 5: Get the last book

Path:

$.store.book[-1]

Negative indices count from the end

Example 6: Get first two books

Path:

$.store.book[0:2]

Array slice: start index (inclusive) to end index (exclusive)

Example 7: Filter books by price

Path:

$.store.book[?(@.price < 10)]

Returns books with price less than 10

Example 8: Filter books with ISBN

Path:

$.store.book[?(@.isbn)]

Returns books that have an ISBN property

Example 9: Get specific properties

Path:

$.store.book[0,2]

Returns the first and third books (union operator)

Filter Expressions

Filter expressions use [?()] syntax with @ representing the current element.

OperatorDescriptionExample
==Equal to[?(@.price == 8.95)]
!=Not equal to[?(@.category != "fiction")]
<Less than[?(@.price < 10)]
<=Less than or equal[?(@.price <= 10)]
>Greater than[?(@.price > 10)]
>=Greater than or equal[?(@.price >= 10)]
&&Logical AND[?(@.price < 10 && @.category == "fiction")]
||Logical OR[?(@.category == "fiction" || @.category == "reference")]

Tips & Best Practices

• Always Start with $

Every JSONPath expression must start with $ to reference the root element.

• Use Dot Notation for Simple Paths

$.store.book is cleaner than $['store']['book']

• Use Bracket Notation for Special Characters

If property names contain spaces or special characters, use bracket notation: $['property name']

• Test Incrementally

Build complex paths step by step. Start with $.store, then add .book, then filters.

• Understand Your Data Structure

Use the graph visualization to understand your JSON structure before writing path expressions.

Common Use Cases

Extract All Values of a Specific Field

$..fieldName

Recursively finds all occurrences of "fieldName" at any level

Get All Array Elements

$.arrayName[*]

Returns all elements in the array

Filter by Multiple Conditions

$.items[?(@.price < 100 && @.inStock == true)]

Combines multiple filter conditions

Get Nested Property from All Items

$.users[*].address.city

Extracts nested property from each array element
